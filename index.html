HISTÓRIA

Como surgiu o Materialize?

O Materialize CSS surgiu como um projeto desenvolvido por estudantes da Carnegie Mellon University.

A ideia principal era combinar os princípios do Material Design com ferramentas que facilitassem o desenvolvimento de páginas web.

O framework passou a oferecer uma coleção de componentes, classes e recursos JavaScript que permitem desenvolver interfaces seguindo uma identidade visual consistente.
