O QUE É?

Conheça o Materialize CSS

O Materialize é um framework front-end que fornece componentes e estilos prontos para ajudar no desenvolvimento de interfaces web.

Material Design

Baseado nos princípios de design desenvolvidos pelo Google, com uma interface moderna e intuitiva.

Responsivo

Permite criar páginas que se adaptam a diferentes tamanhos de tela.

Prático

Possui componentes prontos que aceleram o desenvolvimento de aplicações web.

HISTÓRIA

Como surgiu o Materialize?

O Materialize CSS surgiu como um projeto desenvolvido por estudantes da Carnegie Mellon University.

A ideia principal era combinar os princípios do Material Design com ferramentas que facilitassem o desenvolvimento de páginas web.

O framework passou a oferecer uma coleção de componentes, classes e recursos JavaScript que permitem desenvolver interfaces seguindo uma identidade visual consistente.
